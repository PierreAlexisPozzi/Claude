# Blender assets

Meshes and textures for the game are modelled, baked and exported with **Blender 5.3 used as a Python module**
(`bpy` from PyPI, Python 3.13). Nothing is hand-edited: every asset is generated by these scripts.

```bash
python3.13 -m venv .bpyenv && .bpyenv/bin/pip install -r blender/requirements.txt
.bpyenv/bin/python blender/trees.py        # spruces: needle atlas, 3 near variants, far silhouette
.bpyenv/bin/python blender/people.py       # skier parts and posed skiers for the other characters
.bpyenv/bin/python blender/materials.py    # tileable PBR detail maps for timber, planks and masonry
python3 tools/embed_assets.py              # embeds assets/ into game.html (base64, one JSON block at the end)
./build.sh
```

- Blender is Z-up; the glTF exporter writes the game's Y-up. Units are metres.
- Only geometry is exported (positions, normals, UVs, vertex colours with baked ambient occlusion).
  The game applies its own PBR materials, so tunnel shading, instance tints and quality tiers keep working.
- Textures are rendered or baked with Cycles using the Standard view transform (albedo, not a lit image).
